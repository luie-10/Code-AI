MiniUnityLLM

Unity C# 코드를 입력받아 상속·역할·변수 흐름을 문장으로 생성하는 1.42M 파라미터 LLM. 바이트 BPE 토크나이저부터 어텐션 블록, 학습 루프까지 전부 이 프로젝트 안에서 직접 구현하고 CPU에서 학습했습니다. 교사(teacher)는 앞서 만든 규칙 기반 분석기 UnityLens입니다.

솔직한 결론: 형식과 상속은 학습했지만 내용은 아직 약합니다. 상속 정확도 96%, 형식 준수 88%까지 올라왔지만 필드 이름 재현은 1.4%에 그칩니다. 1.4M 파라미터·555개 예제로는 처음 보는 코드의 변수명을 안정적으로 옮겨 적지 못하고, 긴 파일에서는 토큰 반복이 생깁니다. 실사용 코드 해석기로는 부적합하며, 정확한 분석이 필요하면 UnityLens(규칙 기반)를 쓰고 이 모델은 "LLM을 밑바닥부터 만든다"는 실험으로 봐야 합니다.

구성

  • common.py — BPE 토크나이저(학습/인코딩/디코딩), 프롬프트·라벨 포맷
  • model.py — CausalSelfAttention · MLP · Block · GPT (샘플링 포함)
  • train.py — 학습 루프, cosine 스케줄, val 평가, 체크포인트
  • chat.py — C# 파일 → 분석 텍스트 생성 CLI
  • eval_model.py — 상속/필드/역할/형식 지표
  • data_gen.py — 16개 아키타입 × 34 변형 = 544개 합성 스크립트
  • analyze_batch.js — UnityLens 분석기로 라벨 생성 (teacher)
  • ckpt/model.pt — 학습된 가중치 · ckpt/tokenizer.json — BPE 병합 규칙
