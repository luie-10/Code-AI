# UnityLens — Unity C# 구조 · 변수 추적기

C# 스크립트를 **브라우저에서 즉시 파싱**해 상속 관계, 클래스 역할, 변수의 읽기/쓰기 흐름을 보여주는 단일 HTML 도구입니다. 설치도, 서버도, 코드 전송도 없습니다.

## 쓰는 법

1. `UnityLens.html`을 더블클릭해 엽니다 (Chrome / Edge / Safari 최신 버전).
2. 우측 상단 **코드 추가** → `.cs` 파일을 여러 개 한 번에 선택하거나, 코드를 붙여넣고 **분석**.
3. 탭을 오갑니다.
   - **개요** — 타입 지도, 상속 분포, 발견된 이슈, 파일 밖 참조
   - **클래스** — 베이스/인터페이스, 판정된 역할과 근거, 생명주기, 필드·메서드, AI 해설
   - **변수 추적** — 변수별 선언 → 사용 지점(읽기/쓰기/외부 참조)을 줄 번호와 코드로 추적
   - **배선도** — 타입 간 참조를 PCB 스타일로 표시 (노드 클릭 = 이동)
   - **소스** — 선택한 변수가 쓰인 줄 강조
4. **리포트 내보내기** → `unitylens-report.md` 다운로드.

주소 끝에 `#vars/PlayerMove`처럼 붙이면 그 상태로 바로 열립니다.

## 분석 방식

- **토크나이저**: 주석(`//`, `/* */`, `///`), 문자열(`"…"`, `@"…"`, `$"…"`), 문자 리터럴을 정확히 건너뛰고 토큰화 → 중괄호 깊이로 타입/멤버 경계를 판정.
- **선언 파싱**: 클래스·구조체·인터페이스·enum, 베이스 목록, 어트리뷰트(`[SerializeField]`, `[CreateAssetMenu(...)]`), 필드(다중 선언 포함), 프로퍼티, 메서드·생성자, 매개변수, 지역 변수.
- **변수 흐름**: 메서드 본문에서 각 식별자의 읽기/쓰기를 판정 — `=`는 쓰기, `+=`·`++`는 읽기+쓰기, `out`은 쓰기, 나머지는 읽기. `this.x`는 소유 멤버로, `obj.x`는 다른 객체로 구분.
- **파일 간 추적**: `SelectScene.SelectedData.playerSpeed` 같은 체인을 끝에서부터 멤버 인덱스와 대조해 **다른 파일의 필드/메서드**까지 연결합니다.
- **역할 판정**: ScriptableObject, 정적 Instance, `Instantiate`, `Destroy`, `transform.Translate`, Input System, `SceneManager`, EventSystem 인터페이스 등 시그널을 점수화하고 근거를 함께 표시합니다.
- **이슈 탐지**: 파일명≠클래스명(MonoBehaviour 부착 불가), 쓰기만 하는 필드, `Update` 안 `Find*`/`GetComponent`, `GetComponent` null 미검사, 빈 배열 인덱스, 정적 상태, `CreateAssetMenu` fileName 중복 등.

## 한계 (정직하게)

- `#if` 전처리기는 평가하지 않고 양쪽 코드를 모두 읽습니다.
- 리플렉션, UnityEvent 구독, 애니메이션 이벤트처럼 **문자열/간접 호출로 연결되는 사용은 추적하지 못합니다.**
- 보간 문자열 `$"…{expr}…"` 내부의 식은 하나의 문자열로 취급합니다.
- 지역 변수는 선언만 수집하며, 사용 지점 추적은 필드·프로퍼티가 대상입니다.
- 규칙 기반 분석이라 "이 코드가 게임에서 어떤 재미를 만드는가" 같은 의미 해석은 하지 않습니다. 내장된 10개 샘플의 해설만 사람이 작성한 큐레이션입니다.
